VARIABLES DE ENTORNO REQUERIDAS
────────────────────────────────
Para PayPal (agregar en cPanel → Variables de entorno):

  NEXT_PUBLIC_PAYPAL_CLIENT_ID=tu_client_id_de_paypal
  PAYPAL_CLIENT_ID=tu_client_id_de_paypal
  PAYPAL_CLIENT_SECRET=tu_client_secret_de_paypal
  PAYPAL_MODE=live    (o "sandbox" para pruebas)

Para obtener credenciales PayPal:
1. Crear cuenta de negocios en https://www.paypal.com/business
2. Ir a https://developer.paypal.com/dashboard/applications
3. Crear app → copiar Client ID y Secret
4. Para sandbox: usar credenciales de sandbox
5. Para producción: usar credenciales live

PASOS DE DESPLIEGUE
───────────────────
1. Subir todo el contenido del ZIP a public_html/ en GoDaddy cPanel
2. Asegurar que los permisos de data/ sean 0755 o 0777 (para escritura PHP)
3. Configurar las variables de entorno de PayPal en cPanel
4. Verificar que .htaccess permita el acceso a /api/servicios.php
5. Probar el flujo de PayPal en sandbox primero
6. Verificar que data/ordenes.json se cree correctamente al hacer una orden

NOTAS IMPORTANTES
─────────────────
• PayPal requiere cuenta de negocios (Business) para recibir pagos
• En sandbox, usar tarjetas de prueba de PayPal Developer
• La facturación SRI real requiere integración con proveedor externo
  (Alegra, Facto, etc.) — pendiente para v36+
• El botón de PayPal solo aparece si NEXT_PUBLIC_PAYPAL_CLIENT_ID
  está configurado. Si no está configurado, se muestra un mensaje
  indicando que PayPal no está disponible.
