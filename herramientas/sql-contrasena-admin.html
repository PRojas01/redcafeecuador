Archivo SQL: base nueva con contraseña de admin

Funciona sin internet: la contraseña no sale de tu navegador. Genera un archivo .sql con todas las tablas de la plataforma (vacías) y la contraseña del admin. El importador de GoDaddy borra las tablas existentes antes de cargarlo: úsalo solo mientras la base no tenga datos reales.

La primera vez que entres a /admin/ con esta contraseña, el servidor la guarda cifrada (bcrypt) y la copia legible desaparece de la base. Borra el archivo .sql de tu equipo después de importarlo.
