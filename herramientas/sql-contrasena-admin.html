Archivo SQL para fijar la contraseña del admin

Funciona sin internet: la contraseña no sale de tu navegador. Genera un archivo .sql que importas en la base de datos de la app (phpMyAdmin o la sección Base de datos de GoDaddy → Importar).

La primera vez que entres a /admin/ con esta contraseña, el servidor la guarda cifrada (bcrypt) y la copia legible desaparece de la base. Borra el archivo .sql de tu equipo después de importarlo.
